# ✦ FAS SUN — Haute Couture Digitală

> *Where fashion becomes art.*

FAS SUN este o experiență web premium care combină **moda de lux**, **design modern** și **interactivitate dinamică**, oferind utilizatorilor o platformă elegantă pentru explorarea materialelor, culorilor și stilurilor contemporane.

---

## ✨ Preview

🌐 Platformă web interactivă cu:

* design dark luxury + accente gold
* animații fluide și experiență cinematică
* componente dinamice bazate pe API-uri

---

## 🧠 Concept

FAS SUN nu este doar un site — este o **viziune digitală asupra modei**:

* 🧵 materiale premium
* 🎨 tendințe cromatice generate dinamic
* 👑 diferențiere între branduri și piese unicat
* 📸 lookbook inspirațional
* 💬 comunitate cu recenzii reale

---

## 🚀 Funcționalități

### 🎬 UX & Interfață

* Preloader animat cinematic
* Glass navbar cu blur
* Layout responsive (mobile + desktop)
* Scroll animations (Intersection Observer)

---

### 🧵 Materiale Premium

* Listă statică de textile (bumbac, mătase, lână etc.)
* Carduri moderne cu hover effects

---

### 🎨 Culori dinamice (API)

* Integrare cu API extern (`thecolorapi.com`)
* Generare automată schemă cromatică
* Fallback în caz de eroare

---

### 👑 Produse fashion (API)

* Integrare cu `fakestoreapi`
* Filtrare:

  * branduri premium
  * piese unicat
* Skeleton loading UI

---

### 🎞 Slider Accesorii

* Slider custom (fără librării)
* Responsive:

  * 1 / 2 / 4 items per view
* Navigare cu butoane

---

### 📸 Lookbook

* Grid vizual inspirat din editorial fashion
* imagini lazy-loaded

---

### 💬 Sistem Recenzii (complex 🔥)

* API + localStorage (hibrid)
* Upload imagine
* Redimensionare automată (canvas)
* Salvare persistentă
* Rating emoji 😍 / 😕

---

### ⚡ Alte features

* Lazy loading imagini
* Skeleton loading
* Escape HTML (security)
* Smooth scroll navigation

---

## 🛠️ Tehnologii utilizate

* HTML5
* CSS3 (custom design system + variables)
* Vanilla JavaScript (ES6+)
* Fetch API
* LocalStorage
* Canvas API (image processing)
